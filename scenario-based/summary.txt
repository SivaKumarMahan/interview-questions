1. Question : “You are fetching Azure Key Vault secrets via Terraform and creating Kubernetes secrets in AKS. Secrets rotate every 3 months — how will you automate updating these secrets into AKS"

My Approach:

I explained that there are multiple automation options depending on architecture:

Best Practice:
Use Azure Key Vault CSI Secret Store Driver
➡️ Secrets are not stored in Kubernetes at all
➡️ Pod mounts secrets directly from Key Vault
➡️ Automatic refresh — no pipeline or Terraform needed
➡️ Most secure & event-driven


---

2. ✅ If Kubernetes Secrets must be updated Use Azure Function + Event Grid
➡️ Key Vault triggers event on secret version change
➡️ Azure Function applies update (Terraform or kubectl)
➡️ Automatically restarts pods if necessary

Architecture:

Key Vault → Event Grid → Function App → AKS Rollout Restart

Why not ArgoCD here?
🔸 ArgoCD relies on Git changes
🔸 Secret rotation in KV doesn’t modify Git
➡️ Not the right fit for autonomous secret refresh


---

3. ✅ Simple Time-Based Automation 📌 GitHub Actions or Azure DevOps Scheduler
Runs Terraform every 3 months:

on:
 schedule:
 - cron: "0 0 1 */3 *" # Every 3 months

➡️ Cost-effective
➡️ Easy to maintain
