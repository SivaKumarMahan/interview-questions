# Real Interview Questions

Question sets from real interviews, one file per company, plus a tracker for every round you attend.

## Interview tracker

Add one row per round, right after the interview while you still remember the details. Over time this shows which topics come up most, so you know what to revise next.

**How to fill in each column:**

- **Company:** the company name, and the client name if you went through an agency.
- **Date:** use `YYYY-MM-DD`, so the table sorts by date.
- **Round:** for example Screening, Technical 1, Technical 2, System design, Managerial, or HR.
- **Topics asked:** a short list of the main topics. Put the full questions in the company's file below.
- **Outcome:** for example Moved to next round, Offer, Rejected, or Waiting.
- **Notes:** what went well, what you would answer differently, and which repo file to revise.
