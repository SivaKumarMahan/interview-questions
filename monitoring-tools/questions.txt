1. Have you worked with Prometheus, Grafana, and ELK?
Answer: Prometheus collects time-series metrics, Grafana visualizes dashboards, and ELK/OpenSearch centralizes logs. In Kubernetes, Prometheus commonly scrapes exporters and kube-state-metrics, Grafana shows health dashboards, and log agents such as Filebeat or Fluent Bit ship container logs.

2. What is Azure Monitor?
Answer: Azure Monitor is Azure's observability platform for collecting, analyzing, alerting, and acting on metrics and logs from Azure resources, applications, and infrastructure.

3. What is Log Analytics?
Answer: Log Analytics is the Azure Monitor feature used to query logs stored in a Log Analytics workspace using KQL. It is commonly used for troubleshooting, dashboards, alerts, and compliance reporting.

4. What is Application Insights?
Answer: Application Insights is an application performance monitoring service. It collects request rates, response times, failures, dependencies, exceptions, traces, availability tests, and distributed transaction telemetry.

5. What is Loggly used for?
Answer: Loggly is a cloud log management tool used to aggregate, search, analyze, and alert on application and infrastructure logs. It is useful when teams want hosted log analytics outside native cloud tooling.

6. What is the configuration file of Prometheus?
Answer: The main file is `prometheus.yml`. It defines scrape intervals, scrape targets, rule files, alerting configuration, service discovery, and relabeling.

7. Should alerts be configured in Prometheus or Grafana?
Answer: Metric alert rules are commonly defined in Prometheus and routed through Alertmanager. Grafana can also manage alerts, especially for dashboard-based or multi-data-source alerts. The best choice depends on ownership and reliability requirements.

8. How do you configure an alert for disk usage greater than 80%?
Answer: With node exporter metrics, create a Prometheus alert rule that calculates used disk percentage and fires above 80% for a sustained period.

Example:
```yaml
- alert: DiskUsageHigh
  expr: 100 - ((node_filesystem_avail_bytes{fstype!~"tmpfs|overlay"} * 100) / node_filesystem_size_bytes{fstype!~"tmpfs|overlay"}) > 80
  for: 10m
  labels:
    severity: warning
  annotations:
    summary: "Disk usage is above 80%"
```

9. How do you monitor Kubernetes clusters?
Answer: Monitor node CPU, memory, disk, network, pod restarts, pending pods, deployment availability, API server latency, etcd health, CoreDNS errors, ingress latency, and application SLOs. Common tools are Prometheus, Grafana, Alertmanager, kube-state-metrics, Loki/ELK, Jaeger, OpenTelemetry, and cloud-native monitoring.

10. How do you troubleshoot high latency on a load balancer?
Answer: Check load balancer metrics, backend health, target response time, TLS termination, connection limits, DNS, ingress/controller logs, pod readiness, application latency, network policies, and node resource pressure.

11. How do you create an Azure Monitor alert?
Answer: Choose the target resource, select a metric or log query condition, configure threshold and evaluation frequency, attach an action group, set severity, and test notification routing.

12. What are Azure diagnostic settings?
Answer: Diagnostic settings route platform logs and metrics from Azure resources to Log Analytics, Storage Account, Event Hub, or partner tools. They are required for many resource-level logs.

13. What is KQL?
Answer: Kusto Query Language is used to query Azure Monitor and Log Analytics data. It supports filtering, projection, joins, summarization, time charts, and parsing log fields.

14. What are golden signals in monitoring?
Answer: Golden signals are latency, traffic, errors, and saturation. They help measure user experience and system health better than isolated infrastructure metrics alone.

15. How do you reduce alert noise?
Answer: Use meaningful thresholds, alert windows, severity levels, deduplication, routing, maintenance windows, SLO-based alerts, and clear runbooks. Remove alerts that do not require action.

16. How do you implement Kubernetes cluster-level monitoring using Prometheus?
Answer: Deploy Prometheus with Helm or an operator, scrape node exporter, kube-state-metrics, API server, CoreDNS, ingress, and application metrics, then visualize in Grafana and alert through Alertmanager.

17. How do you integrate Prometheus Alertmanager with Slack or Teams?
Answer: Configure Alertmanager receivers with Slack or webhook integration, route alerts by severity/team, add useful labels and annotations, and test alert delivery with a non-production alert.

18. How do you monitor API performance in Azure API Management or an API gateway?
Answer: Track latency, request count, error rate, backend response time, throttling, and dependency failures. Use Application Insights, Azure Monitor, gateway logs, dashboards, SLOs, and alerts.

19. How do you design observability for serverless components?
Answer: Use structured logs, distributed tracing, correlation IDs, metrics, and centralized dashboards. For Azure Functions, use Application Insights and Log Analytics; for multi-cloud, standardize telemetry with OpenTelemetry.
