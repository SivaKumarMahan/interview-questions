Azure Network Watcher is a network performance monitoring, diagnostic, and analytics service that monitors Azure networks. The Network Watcher Agent virtual machine (VM) extension is a requirement for capturing network traffic on demand and using other advanced functionality on Azure VMs. It's used by connection monitor, connection troubleshoot, and packet capture.

𝙒𝒉𝙞𝒍𝙚 𝙬𝒐𝙧𝒌𝙞𝒏𝙜 𝙬𝒊𝙩𝒉 𝑾𝙞𝒏𝙙𝒐𝙬𝒔 𝑽𝙈𝒔 𝒊𝙣 𝘼𝒛𝙪𝒓𝙚, 𝑰 𝒐𝙗𝒔𝙚𝒓𝙫𝒆𝙙 𝙖𝒏 𝒊𝙣𝒕𝙚𝒓𝙚𝒔𝙩𝒊𝙣𝒈 𝒃𝙚𝒉𝙖𝒗𝙞𝒐𝙧:

When the Azure Network Watcher extension (NetworkWatcherAgentWindows) is not pre-installed, and you initiate a Connection Troubleshoot (either from the Azure portal or CLI) — for example, to test connectivity to a public URL, an on-prem server, or another Azure VM (within the same or different VNET) — Azure automatically installs the extension in the background.

⚠️ 𝐈𝐦𝐩𝐨𝐫𝐭𝐚𝐧𝐭 𝐍𝐨𝐭𝐞:
This automatic installation always uses the latest available version, and does not give you the option to select a specific version.

3. Moving Azure Resources Smoothly Between Resource Groups

Moving Azure Resources Smoothly Between Resource Groups
I recently moved several Azure resources between resource groups and wanted to share a key insight for anyone planning a similar operation. 
During the move, both the source and destination resource groups are locked—this means you cannot create, update, or delete resources in either group until the move is completed.

However, existing resources continue operating without interruption—for instance, a virtual machine or a database remains fully functional throughout the transition, and applications relying on them experience no downtime.

Azure allows up to four(4) hours for the move operation to complete, though most moves finish much sooner. 

Key Takeaways:
Both source and destination RGs are locked—no write, update, or delete operations allowed.
Resources stay online and functional—no downtime for your apps or services.
⏱ Lock can last up to four hours; planning during low-traffic windows is advisable.
Only one move operation per RG at a time—avoid conflicts.
