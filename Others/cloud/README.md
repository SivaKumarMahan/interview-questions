# Cross-Cloud Interview Topics

This folder contains cloud-neutral and multi-cloud scenarios that do not belong to one provider and are not primarily networking questions.

Current coverage in `scenario-questions.txt` includes:

- GCP and Azure storage encryption
- Cloud IAM incidents, role sprawl, and service-account rotation
- GCP-to-Azure workload migration
- Hybrid and multi-cloud CI/CD
- Azure VM and GCP Cloud Build/Function troubleshooting
- Centralized multi-cloud secret management
- Terraform-based cloud migration
- Cloud cost anomalies and infrastructure scaling

Networking-specific multi-cloud routing, VPN, firewall, and connectivity material is located under `networking/multi-cloud/`.

`summary.txt` covers cloud-neutral three-tier application architecture, request flow, scaling, security, observability, and recovery considerations.
